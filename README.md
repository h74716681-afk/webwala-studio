# Webwala Studio

A responsive one-page agency website for Webwala Studio.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive white-theme styling
- `script.js` — mobile menu and copy-enquiry interaction
- `assets/logo.svg` — vector logo

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. GitHub will show the published website URL in the Pages section.

## Before taking real client enquiries
Add the agency's real WhatsApp number/email and business details. The current enquiry button copies a brief; it does not send messages or collect/store submissions.

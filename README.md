# Webwala Studio

A responsive one-page agency website for Webwala Studio, plus three sample business-site demos.

## Main website
- `index.html` — agency homepage and enquiry form
- `styles.css` — responsive white-theme styling
- `script.js` — mobile menu and WhatsApp enquiry action
- `assets/logo.svg` — vector logo

## Portfolio demos
- `hotel-demo.html` — North House hotel concept
- `cafe-demo.html` — Good Day Cafe concept
- `shop-demo.html` — Field & Form shop concept

These three demo businesses, descriptions, menus, prices, rooms and images are illustrative placeholders. They are not completed client projects and must be replaced with a real client's approved information before delivering a production site.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. GitHub will show the published website URL in the Pages section.

## Before accepting client work
Confirm the scope, content, price, domain/hosting ownership, revision limits, delivery date and any third-party subscription costs in writing. The current contact form opens WhatsApp with a prepared message; it does not store enquiries in a database.
